NusaStat — situs statistik Indonesia yang berjalan luring dari berkas statis: angka resmi BPS 2010–2025 tentang penduduk, ekonomi, dan pembangunan manusia, dengan grafik SVG, tabel penjelajah data yang bisa dicari dan diurutkan, serta sumber dan tahun pada setiap angka.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 di peramban desktop atau ponsel. Situs ini tidak memakai jaringan sama sekali: semua data tersimpan di `app/data.js`.
